# AGENTS.md

The full guidance for AI coding agents (and humans) working in **SAGA UI** lives in
**[CLAUDE.md](CLAUDE.md)**.

👉 **Read [CLAUDE.md](CLAUDE.md) before making any changes.** It covers the project overview
(React frontend + Python BFF), repository structure, run/lint/type-check commands, the
mandatory Docker build check, key constraints (no direct SAGA calls from the browser, one API
client, no hard-coded secrets, English only, Mantine only), coding conventions, and the Git
commit / branch / pull-request workflow (`main` and `develop` are protected — use a feature
branch + PR).

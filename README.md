# SAGA UI

The web interface for **SAGA** (*Self-organizing Archive for Generative Agents*) — a modern UI for the [SAGA](https://github.com/mlauf-labs/saga-core) document archive.  
Manage, search, preview and download documents through a clean, three-column UI.

> **Status:** Feature-complete · Tests passing · Docker-ready

---

## Features

| Area | Details |
|------|---------|
| **Authentication** | Static username / password login with signed HttpOnly session cookies |
| **Category tree** | Left column – hierarchical category tree generated by Saga's LLM pipeline |
| **Document list** | Centre column – paginated list with status badges, MIME icons and metadata |
| **Search** | Header search bar – hybrid keyword + semantic search with filters |
| **Detail & Preview** | Right column – metadata, status polling, inline preview for PDF / images / Markdown |
| **Management** | Upload (multi-file drag & drop), replace, delete with confirmation dialogs |
| **Health banner** | Dismissible warning when Saga is unreachable |
| **Error boundary** | Graceful fallback on unexpected render errors |

---

## Architecture

```
Browser (React/Vite SPA)
        │  session cookie
        ▼
FastAPI BFF  (Backend-for-Frontend)
        │  Bearer token
        ▼
Saga REST API  (separate server)
```

A **Backend-for-Frontend (BFF)** keeps the Saga Bearer token server-side,
handles authentication and proxies every API call.  
Details in [`docs/requirements/03-architecture.md`](docs/requirements/03-architecture.md).

**Stack:** React 19 · Vite · TypeScript · Mantine 9 · TanStack Query  
→ FastAPI · Python 3.12 · uv · uvicorn  
→ Docker (multi-stage build)

## Quick Start with Docker

Two compose files are provided depending on your setup:

| File | Use case |
|------|---------|
| `docker-compose.yml` | UI only – connect to an **existing** Saga instance |
| `docker-compose.full.yml` | **Full stack** – starts Saga + all its dependencies + the UI together |

---

### Option A – UI only (Saga already running)

#### Prerequisites
- Docker ≥ 24 with Docker Compose v2
- A running Saga instance reachable from the container

```bash
cp .env.example .env
```

Fill in `.env`:

```env
SAGA_BASE_URL=http://your-saga-host:8000
SAGA_API_TOKEN=your-bearer-token
UI_USERNAME=admin
UI_PASSWORD=choose-a-strong-password
SESSION_SECRET=<python -c "import secrets; print(secrets.token_hex(32))">
```

```bash
docker compose up -d --build
# UI → http://localhost:8088
```

---

### Option B – Full stack (Saga + UI together)

#### Prerequisites
- Docker ≥ 24 with Docker Compose v2
- The `saga-core` repository checked out as a **sibling** of this repo (both under
  the same parent folder):
  ```
  parent/
  ├── saga-core/
  └── saga-ui/          ← this repo
  ```

```bash
cp .env.full.example .env.full
# Edit .env.full – fill in all values marked ← CHANGE
```

```bash
docker compose -f docker-compose.full.yml --env-file .env.full up -d --build
```

After the first start, pull the Ollama models (once, takes a few minutes):

```bash
docker compose -f docker-compose.full.yml exec ollama ollama pull llama3.1:8b
docker compose -f docker-compose.full.yml exec ollama ollama pull nomic-embed-text
```

| Service | URL |
|---------|-----|
| Saga UI | http://localhost:8088 |
| Saga API | http://localhost:8000 |
| MinIO Console | http://localhost:9001 |
| OpenSearch Dashboards | http://localhost:5601 |
| Ollama | http://localhost:11434 |

To stop everything:

```bash
docker compose -f docker-compose.full.yml --env-file .env.full down
```

---

### Running on a non-default port

```env
# .env or .env.full
BFF_PORT=9090
```

## Local Development

### Prerequisites

- **Python ≥ 3.11** and [**uv**](https://docs.astral.sh/uv/) (`pip install uv`)
- **Node.js ≥ 22** and npm

### 1. BFF (Backend-for-Frontend)

```bash
cd bff
cp ../.env.example ../.env   # once only – fill in values
uv sync                      # creates .venv and installs dependencies
uv run uvicorn app.main:app --reload --port 8088
```

### 2. Frontend (in a separate terminal)

```bash
cd frontend
npm install
npm run dev
# → opens http://localhost:5173
# /api and /health requests are proxied to the BFF on port 8088
```

### Running the tests

```bash
# BFF
cd bff
uv run pytest -v

# Frontend
cd frontend
npm test
```

## Configuration Reference

All settings are read from environment variables (or `.env` in the working directory).

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `SAGA_BASE_URL` | ✅ | `http://localhost:8000` | Saga API base URL |
| `SAGA_API_TOKEN` | ✅ | – | Bearer token for Saga |
| `UI_USERNAME` | ✅ | `admin` | Login username for the UI |
| `UI_PASSWORD` | ✅ | `admin` | Login password for the UI |
| `SESSION_SECRET` | ✅ | – | Min 32-char random string for cookie signing |
| `SESSION_MAX_AGE` | – | `28800` | Session lifetime in seconds (default: 8 h) |
| `MAX_UPLOAD_BYTES` | – | `104857600` | Max single file upload size (default: 100 MB) |
| `LOG_LEVEL` | – | `INFO` | Uvicorn/Python log level |
| `BFF_PORT` | – | `8088` | Host port exposed by Docker Compose |
| `CORS_ALLOW_ORIGINS` | – | – | Comma-separated list of extra CORS origins |
| `DEBUG` | – | `false` | Enables FastAPI docs UI and hot-reload |
